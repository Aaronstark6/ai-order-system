# ai-order-system V2.5 稳定版状态说明

## 当前版本状态

ai-order-system 当前处于 V2.5 稳定版整理状态。本阶段以稳定现有数据流、Excel 导出和产品描述生成为主，不建议在同一轮中混入大规模架构调整。

## 当前核心功能

- AI解析客户聊天内容
- 普通字段确认
- 字段库管理
- 多模板映射
- 文档编号生成
- 产品描述生成
- 来源前缀标记：[AI] / [模板] / [系统] / [人工]
- Excel模板导出
- 日期导出 YYYYMMDD
- 本地同步导出

## 当前重要规则

- 网页日期可以用浏览器 date input 显示
- 导出 Excel 时日期统一 YYYYMMDD
- 产品描述网页中保留来源标记
- Excel导出时去掉来源标记
- 暂不使用 Excel 富文本红字
- 系统字段 key 不能删除或修改

## 当前不建议做的事

- 暂不做 Excel 富文本红字
- 暂不做大规模前端重构
- 暂不做数据库重构
- 暂不做多用户登录
- 暂不一次性重构产品描述 AI 生成逻辑

## 每次修改后的测试清单

- AI解析是否正常
- 普通字段是否显示
- 日期是否显示稳定
- 文档编号是否正常
- 产品描述是否生成
- 产品描述前缀是否正常
- Excel是否能生成
- Excel产品描述是否去掉前缀
- Excel模板格式是否保持
- 下载和同步按钮是否正常

## 下一步建议

- 产品描述生成稳定化
- AI输出结构化 JSON
- 程序按模板拼装产品描述
- 来源标记从按行判断升级为按字段判断
