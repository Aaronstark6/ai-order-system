# docs 目录说明

`docs/` 目录用于长期保存 ai-order-system 的项目说明、开发记录、设计文档和问题复盘。

根目录的 `PROJECT_STATUS.md`、`PROJECT_STRUCTURE.md`、`VERSION_HISTORY.md`、`TASKS.md`、`COLLAB_SYNC.md` 更适合作为新聊天快速同步项目状态的入口。`docs/` 则适合保存更详细、更长期的资料。

后续可以放入：

- 详细设计文档。
- 业务规则说明。
- Excel 模板说明。
- V4 Schema 设计说明。
- Layout Engine 设计说明。
- 开发记录和问题复盘。
- 给非专业用户看的操作手册。

当前新增文档：

- `docs/V4_INTEGRATION_CHECKLIST.md`：V4 接入正式流程前检查清单，记录 V4 当前能力、暂不接入首页原因、接入条件、建议策略和风险提示。

当前已有历史状态文档 `docs/project_status.md`。如果其中内容出现乱码或过时，建议逐步把有价值的信息整理到新的根目录管理文档中，而不是直接删除。
