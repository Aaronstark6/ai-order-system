选择模板映射

请选择一个映射。不同映射对应不同 Excel 模板和不同字段单元格设置。

普通字段单元格设置

适合“一个字段值写入一个单元格”的情况。勾选“使用”并填写单元格，例如：客户名称 → B3。 可填写默认值：首页订单确认区在解析结果为空时会自动带出，仍可在前端修改；导出时若仍为空，后端也会用该默认值写入 Excel。 文档编号、业务员、成交日期、产品编码等相关字段请在下方「文档编号设置」中配置，不会出现在本表中。

使用 中文名 Key 类型 必填 说明 Excel单元格 默认值

组合单元格设置

适合“一个 Excel 单元格里包含多组关键字和值”的情况。可以用 {字段key} 作为占位符，一行一组。


文档编号设置

此处配置文档编号的生成规则、默认值及写入 Excel 的单元格；与普通字段映射分离，避免混淆。

文档编号规则可用占位符：
{sales_name}、{company_code}、{deal_date_yyyymmdd}、{sequence}、{product_code} 及任意订单字段 key。

产品编码规则可用占位符：
{salesperson_code}、{product_index_or_day}、{product_abbr}、{dosage_form_code} 等。

剂型代码映射（产品剂型 → 代号）：
硬胶囊/胶囊=C，软胶囊=S，软糖=G，滴剂=D，压片=T，固体饮料/粉末=P，精油=O，凝胶=N

示例文档编号：Anna-GS20260318A01-AN211CLBD
